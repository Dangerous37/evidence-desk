# Evidence review contract
A source has a unique ID, revision and plain text. A submitted claim contains a statement, source ID, expected revision and an exact quotation. Character offsets use JavaScript UTF-16 indexing. Each claim receives a provenance verdict. A unique quotation in the expected revision is eligible for human sign-off. Missing, ambiguous or stale evidence blocks export as approved. Human sign-off binds the complete claim and source version and bytes by SHA-256. Editing either invalidates the prior sign-off. Evidence provenance and semantic support are separate checks.
